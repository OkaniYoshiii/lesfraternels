## Installation

Ce projet utilise la librairie `github.com/h2non/bimg` pour la manipulation d'images (redimensionnement, compression etc ...) qui nécessite l'installation de la librairie `libvips` pour fonctionner.

Pour les distributions Linux, cela peut être réalisé gra^ce aux commandes suivantes :

```shell
sudo apt install libvips && sudo apt install libvips-dev
```
